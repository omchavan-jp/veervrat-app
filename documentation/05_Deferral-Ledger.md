## Maintaining this index

Link source/spec, existing issue and observed outcome when updating a row. Mark only the
satisfied slice. If no exact issue is established, retain the gap for triage rather than
automatically creating work. Explicit deferral is not a delivery commitment or approved priority.

Historical archives and `spec/open/*` retain dated provenance; do not rewrite frozen records to
match this index. Before new work, check current issues and the [redesign deferred register](../product-design/00-governance/deferred-topics.mdx).
Redesign questions do not silently decide current product gaps. This reconciliation changes
no behavior, decision rights, issue state, ownership assignments or deployment configuration.
