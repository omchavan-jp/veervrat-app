## Cross-feature cases

| Case | Reconciliation |
| --- | --- |
| Followers article becomes Public; unpublish then republish | Existing discussion follows article audience and publication. Original authorship and discussion persist across unpublishing. |
| Primary and specific guide overlap | Primary has broad independent scope. Specific guide is effective for closure. Losing Primary does not terminate the independently accepted specific relationship. |
| A replaced before B concludes | B retains evolving concluded history read-only. A's valid request allows narrow feedback only. Blocking revokes historical access and cancels requests; unblock does not restore them. |
| Guide contribution shared later | Journey history setting covers attributed contributions and historical guide identity. Current effective guide identity can be visible with sharing Off. Private messages and notes stay separate. |
| Unrelated sender requests; established following ends | Request permitted. Reply accepts; decline silent. Established communication persists, while one-sided messages alone through former following do not establish permission. |
| Suspension and later reversal | Owner publication and audience settings remain stored. Account override hides owned shared records and discussion branches elsewhere. Reversal respects independent moderation and does not restore terminated relationships. |
| Messaging restriction and private Journey report | Ordinary messaging restriction can preserve formal guidance. Report gives limited case context, not general private access. |
| Recover active Journey | Record and history restored, Journey Solo even if formerly Primary-derived. Owner can explicitly choose either existing guidance mode. Independent Primary basis stays valid; cancelled requests stay cancelled. Recoverable unconcluded Journey blocks a duplicate. |
| Recover account before expiry | Previously active accepted relations resume subject to restrictions and counterpart eligibility. Pending requests stay cancelled. |
| Delete shared assessment | Journey and incorporated discovery response remain subject to own audience. Source unavailable until recovery. |
| Delete published article | Entire branch and reactions hidden, restored within X except separately moderated material, erased at expiry subject to legal retention. Independently adopted Resource survives. |
| Retire used expression / delete reference source | Existing practice and historical meaning survive. Used developmental item cannot be hard-deleted. Resource/undertaking source deletion makes references unavailable. |
| Last Admin attempts exit, revocation or suspension | Another active Admin required. Audited out-of-band recovery remains available for emergencies. Suspended Vratarthi can request exit via restricted management. |
