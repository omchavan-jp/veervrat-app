# components

## Overview

Groups the documented components listed below.

## Subdirectories & Boundaries

- [auth](./auth/README.md): Reusable authentication layout, branding, verification resend and feedback components.
- [blog](./blog/README.md): Rich text blog creation and editing UI.
- [chat](./chat/README.md): Rich chat composition, entity mention search and document rendering.
- [dashboard](./dashboard/README.md): Localized dashboard greeting, primary action, statistics and suggestions.
- [experience](./experience/README.md): Client components for creating and editing experience logs, selecting entity tags, and extracting text previews.
- [invitations](./invitations/README.md): Displays received invitations and their response actions.
- [journey](./journey/README.md): Journey exposure and challenge tabs, reusable ERC pool and item controls, custom creation, and resolution check-ins.
- [layout](./layout/README.md): Authenticated application chrome, navigation and notification UI.
- [shared](./shared/README.md): Shared localization, navigation, CMS information, consent and browser-cache helpers.
- [study](./study/README.md): Study-specific informational modal adapter.
- [ui](./ui/README.md): Reusable styled UI primitives and async state components.
